# What earns a guard, a scan, or a spec

The [change and test policy](../change-policy.md) is the shared rule for coding
agents and reviewers. It covers code growth, test value, source scans, the two
existing dev-config ratchet exceptions, and subtractive verification work.

Apply it when writing a dispatch and reviewing its result. Keep this entrypoint
for existing links; do not maintain a second copy of the rules here.
